# Harmonic Vision GeoNames snapshots

Versioned public GeoNames geographic reference data and derived search indexes, licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Source: [GeoNames](https://www.geonames.org/), from the [official data dump](https://download.geonames.org/export/dump/). See each release for exact input checksums, derived-index manifest and attribution.

This repository contains geographic reference data only. Application source, credentials, customer reports and operational receipts do not belong here. Consumers must pin and verify exact asset hashes; updating a release or upstream file never authorizes silently accepting changed bytes.
